# 见闻攻略与个人准备清单

2026-10-11，客户端版本 0.9.3+34。

## 使用

- 写见闻新增「攻略」，切换后展示标题、正文、关联地点、可增删的准备清单和最多九张照片。其他类型保留原来的文字/照片编辑方式。类型切换不会丢失标题或准备项；草稿保存这些字段。
- 右上角发布改为纸面红字、手绘箭头和铅笔下划线。提交过程中显示转圈与「发布中」，禁止重复提交/编辑/离开；失败保留草稿。
- 景点游玩准备中的「大家的攻略」按景点展示最近最多 12 则可见攻略。「写一份」预选攻略类型及该景点。首篇可直接加入准备，其他点击进入见闻详情查看完整清单、评论和导入入口。原门票、预约和官方配置保留，不以用户清单替代。
- 导入会加入本机「我的出游」，按景点保存清单快照和原文、作者。重复导入同一帖子不会复制条目，也不会覆盖完成状态。可勾选、添加/删除自定义项。原文后续删除不抹除已导入快照，查看原文仍受公共 API 可见性约束。
- 个人准备与票据使用同一个按 API/账号隔离的本地数据库，暂不跨设备同步；卸载或清理 App 数据会丢失。移除出游会连带删除准备与票据。
- 横图按原比例完整显示，详情和大图外框、加载与失败占位统一为页面纸色，不裁切图片。

## 接口与数据

新增 `guide` 分类，发布 multipart `preparation_items` 为 JSON 数组，元素为 `{title, body}`，最多 12 项，标题必填且最多 60 字，说明选填且最多 300 字。攻略需要标题、正文及至少一项准备，非攻略不接受准备项。公开列表/详情返回准备项，点赞/收藏状态更新不丢失清单。发现接口支持 `route` slug 筛选，分页游标包含该筛选范围。

迁移 `20261011_0021` 为 `community_posts` 增加 nullable JSON 字段；既有动态不受影响。Flutter 钱包 schema 从 1 升级到 2，新建 `guide_imports` 和 `preparation_tasks`，保留已有出游、日期、票据。

CMS 原有官方准备配置及购票链接不变，本次无需部署 CMS；用户攻略通过公共 API 发布，遵循原有鉴权、限量、幂等、防举报可见性及删除规则。

## 部署

先升级 API 和数据库，再使用新版 App；只更新客户端而未迁移后端不能发布攻略。

```bash
cd /root/DeepTravel
git fetch origin codex/v5-client-art-magazine
git checkout codex/v5-client-art-magazine
git pull --ff-only origin codex/v5-client-art-magazine
docker compose build api
docker compose run --rm api alembic upgrade head
docker compose up -d api
curl -fsS http://127.0.0.1:5001/api/v1/health
```

本次仅提交推送，没有改动线上内容或执行线上部署。
