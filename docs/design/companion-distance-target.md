## 选择与距离规则

- 主界面将数字与「距 ××地点」对应起来，点击整个目标行或「换一处」打开目录。自动模式注明「自动发现 · 最近未探索」；全部探索完成后改为「自动发现 · 附近地点」。
- 自动模式优先选择最近的未探索地点；已触发的故事和已听过的故事不再属于未探索。所有地点均已探索时选择附近地点。为避免定位抖动，只有新目标明显更近时才切换，阈值取 25 米、定位精度与旧目标距离的 20% 三者最大值。
- 手动选择只固定距离目标，显示「手动选定 · 距离目标」和「恢复自动发现」。点击目录中的「随脚步，自动发现」也可恢复自动选择。关闭目录不改变选择。
- 距离是设备有效定位到目标片段 `trigger_region.latitude / longitude` 的直线约距，不是路线或区域中心距离，也不是步行导航距离或触发区域边缘距离。小于 1000 米显示整数米，其余显示一位小数公里。
- 只使用当前路线活动随行的真实定位。无定位、模拟模式、样本超过 60 秒、明显来自未来、无效坐标或精度误差超过 200 米时不展示数值。定位误差超过 50 米时提示仍在校准；此显示规则独立于到点触发的 15 秒和地点精度要求。样本到期通过计时器主动清除，不能因没有下一次 GPS 更新而长期保留旧数字。
- 定位暂不可用时，仍可从目录手动选择地点，但距离显示未知。自动目标若已不属于未探索候选集合，不会在失去定位后继续冒充「最近未探索」。
- 手选目标在进入路线目录、个人页等普通导航后保留。明确更换随行路线、结束或替换活动会话、完成旅程、切换账户时重置。开始之前新选择的手动目标可带入本次随行。父页面跟踪路线交接，慢速加载或失败不会绕过旧目标清理。

## 目录与播放保持独立

目录提供地点名称搜索，以及「全部／未探索／已听过」筛选和数量。列表采用按需构建，支持大量地点，不将所有地点铺在随行主页上。打开时有有效距离则按距离排序，否则按路线顺序排序；目录打开后冻结行顺序，仅更新距离和探索状态，避免 GPS 更新时目标行从手指下移走。新增地点追加、已删除地点移除，重新打开目录再重新排序。

选择距离目标不调用播放、触发到达、创建旅程或开启定位接口，不改变播放器当前故事、播放进度或音频所有权。正在讲述时选择其他地点，原讲述继续；关闭目录后的轻提示明确反馈已关注的地点。真正开始随行仍沿用准备确认流程，到点后由用户决定是否播放。

目录关闭按钮触控区为 44×44，行入口提供按钮及选中状态的无障碍说明。键盘弹出或较大系统字体压缩可用高度时，将目录介绍区域移入可滚动内容，保持搜索和筛选可达。

## 公开地点字段与离线兼容

后端片段序列化新增可空字段 `stop_id`、`place_name`。`place_name` 来自同一路线内关联 `Stop.title`，该标题原本就是路线 API 的公开内容；不以片段 `title` 或 `transcript` 作为客户端回退。公开 manifest、旅程 ledger、手动章节和离线包复用同一地点序列化逻辑，原有未发现故事的标题和全文隐藏规则保留。

CMS 地点标题应填写可识别的实际地名，触发坐标应对应现场讲述位置。地点坐标与触发坐标可以按内容需要分别维护，本次距离明确使用触发坐标。客户端不从故事标题推断地名，也不自动改写现有内容；地点标题与故事标题相同不代表数据无效。

Flutter `StoryFragment` 增加 `placeName`、`stopId` 和 `publicPlaceName`。切换音色、更新离线进度、将故事恢复为未发现状态时保留公开地点信息。旧后端或旧离线包没有新字段时，优先使用简短、适合作为名称的公开 `safe_preview`，否则显示「地点 XX」；重新下载离线包后可获得新字段。

离线包继续保存、校验原始 manifest 并从中恢复地点字段。完整离线包包含故事全文，但探索状态只从旅程 ledger 判断；离线恢复会清除尚未发现故事的标题，不将「已经下载」误判为「已经探索」。

无需数据库迁移。后端升级后提供准确公开地点名；旧响应仍可被新版客户端解析。本次没有修改种子内容、CMS 内容、图片地址、音频地址或 OSS 对象。

## 2026-09-30 定位与操作行修正

距离展示不再套用到点触发精度，普通可用定位可先显示约距；超过 200 米误差或 60 秒的样本仍不显示数值。Android 连续定位保留每 3 秒请求，移除最小位移门槛，静止时也可更新；同时请求一次支持网络定位的首个位置，结果不能覆盖较新的实时样本。后台通知文案改为靠近地点提醒，符合手动确认播放规则。

定位流短暂异常后的后续样本可恢复监测；无可用位置时可点信号区右上角重新定位，重启定位不重置音频或旅程。结束操作已移回主操作右侧，窄屏不通过 Wrap 换行；320/360/390 宽度及 1.3 倍字号均有几何布局断言。
