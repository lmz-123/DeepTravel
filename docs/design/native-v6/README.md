## 行为与数据

- 地图位于随刊内部，返回保留刊期；从详情返回保留地图选点、主题和缩放/拖动状态。
- 只展示已发布景区，优先使用目录中心坐标，缺失时使用公开站点坐标；无有效坐标的景区保留文字入口，不生成虚构位置。
- 深圳底图来自 [DataV 440300_full.json](https://geo.datav.aliyun.com/areas_v3/bound/440300_full.json)，随应用离线打包。其他城市使用真实坐标的地点分布示意，界面明确标注，不套用深圳底图。
- 地点圆点和名称均可点击，接近的标签避让并以引线标记真实位置；支持拖动、双指缩放、放大、缩小和查看全城。
- 地图浏览不请求定位、不启动随行，也不自动播放。进入章节仍经过原有选择流程。
- 随行页本身保持既有实现。纯阅读旧路线继续隐藏不可用的景区随行入口；支持随行的路线传递其真实选择。
- 中间“路线”保留原有搜索/筛选和历史入口；本轮未自行加入尚未确认的新核心功能。
- 保留原有随刊拖动/翻页动画；地图入场、选点反馈和地点卡切换遵守系统减少动画设置。
