## 行为与数据

- 地图位于随刊内部，返回保留刊期；从详情返回保留地图选点、主题和缩放/拖动状态。
- 只展示已发布景区，优先使用目录中心坐标，缺失时使用公开站点坐标；无有效坐标的景区保留文字入口，不生成虚构位置。
- 深圳底图来自 [DataV 440300_full.json](https://geo.datav.aliyun.com/areas_v3/bound/440300_full.json)，随应用离线打包。其他城市使用真实坐标的地点分布示意，界面明确标注，不套用深圳底图。
- 地点圆点和名称均可点击，接近的标签避让并以引线标记真实位置；支持拖动、双指缩放、放大、缩小和查看全城。
- 地图浏览不请求定位、不启动随行，也不自动播放。进入章节仍经过原有选择流程。
- 随行页本身保持既有实现。纯阅读旧路线继续隐藏不可用的景区随行入口；支持随行的路线传递其真实选择。
- 中间“路线”保留原有搜索/筛选和历史入口；本轮未自行加入尚未确认的新核心功能。
- 保留原有随刊拖动/翻页动画；地图入场、选点反馈和地点卡切换遵守系统减少动画设置。

## 随刊松手停顿修复（2026-10-09）

基于 `codex/v5-client-art-magazine` 的 `089c32e` 修复。原实现把拖动松手当成从静止开始的箭头动画，重新执行三次 ease-in-out；手指已有速度因此在松手时降到零，出现中途停顿。新增回归在旧实现上稳定复现：750 逻辑像素/秒滑动后，第一个 16ms 的进度只增加约 0.000081，远低于手指每帧约 0.0394 的进度。

松手现在使用手势速度和剩余距离构造单调的三次 Hermite 段，衔接初速度并在落位时降至零。续播时长为 180–460ms，限制曲线斜率以防止快速甩动越界；极低速度或朝相反方向的速度使用有界的回位速度。箭头切换继续使用原来的 820ms 时间线。翻页阈值、手指跟随比例、照片和标题的分层运动轨迹均保持原样。

移除每帧临时创建的标题 TextPainter，第二行用自然宽度布局；在动态透明度和纸边以内单独缓存照片绘制，降低重复排版与着色开销。未更改摄影资源、字体、构图或城市地图入口。

验证：新增 375/750/1500 逻辑像素/秒的双向首帧速度、持续单调推进、460ms 内落位测试，以及接近终点时高速松手不越界测试。完整客户端 **255 项测试通过**；`dart analyze --fatal-infos` 无问题；既有 360/390 静态截图和全部拼贴关键帧逐像素回归通过，没有更新截图基线。自动化验证覆盖衔接逻辑及画面一致性，不代表已测量具体手机的 GPU 帧率。
