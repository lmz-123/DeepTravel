# 深圳现场讲述与试听清单

适用于深圳路线的节点讲述、完整故事和可选拍摄引导。发布前由编辑与试听人员逐项确认；事实、来源和不确定性边界不得因为口语化而改变。

## 写作

- [ ] 先把旅行者放回现场：用“看看前面”“听听身边”“我们往前走一点”等自然提示，指出一个此刻可观察的细节。
- [ ] 再连接经过审核的事实，不把推测、民间说法或规划意图说成已经证实的现场事实。
- [ ] 语气温柔、俏皮但克制，像熟悉这座城市的同行者娓娓道来；不用公文腔、播报腔或过度撒娇。
- [ ] 避免反复使用“第一条线索”“你获得了”“任务完成”等系统话术，让节点之间靠问题和观察自然过渡。
- [ ] 年份、数字、地名、人物和因果关系与已审核 claims、sources 完全等价；不为了顺口增加新结论。
- [ ] 不确定内容要自然说清边界，例如“有一种说法”“资料能说明整体目标，但不能单凭眼前外观断定”。
- [ ] 生僻字、多音字、外语和地方称呼已写入发音提示，并在合成前人工读过一次。
- [ ] 每段只保留一条主要认知线，句子长短有变化，户外走动时第一次听也能跟上。

## 拍摄引导

- [ ] 拍照始终是可选留念，不上传也能继续体验，不使用“必须”“打卡成功才解锁”等强制文案。
- [ ] 只给一个清楚的主体、一个安全站位和一个容易理解的构图建议，不把拍摄步骤讲成摄影课。
- [ ] 引导避免拍清陌生人面部、进入私人区域、站进车道、闸口、人流中心、浪溅区或湿滑高差。
- [ ] 提供“不拍也没关系”“可以稍后补拍”或无障碍替代方案。

## 试听与发布

- [ ] 选用后台保存的温暖普通话女声候选；客户端只展示音色名称与说明，不暴露 provider voice ID、密钥或对象存储路径。
- [ ] 在耳机、手机外放和有环境噪声的户外各试听一次，确认人名、地名、数字、停顿和音量清楚。
- [ ] 情绪温暖自然，速度适合边走边听；没有过快赶词、机械重音、尾音拖长或连续高亢。
- [ ] 节点稿、完整故事、script version 与 transcript hash 完全匹配；任何正文修改都使旧音频失效并重新走试听批准。
- [ ] 所有公开音频 URL 可访问，时长正确，播放结束、暂停、切换路线与首页故事的互斥行为已验证。
- [ ] 发布前再次搜索重复系统语言，并确认上海的内容、音色、音轨、哈希和发布状态没有变化。
