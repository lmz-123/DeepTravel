# 大梅沙实地定位与导览检查表

内容包：`dameisha-remade-coast` / `2026.08-field.1`

本轮目标不是证明历史事实，而是确认 WGS-84 触发中心、公共通行安全、耳机导览连续性和照片任务可执行性。测试时关闭“模拟定位”，保持系统定位和通知权限开启；每站至少停留 60–90 秒，记录 8 个原始样本，不要用高德/腾讯坐标直接覆盖设备 GPS 坐标。

## 每站通用步骤

1. 从触发圈外至少 120 米处锁屏并步行接近，记录是否提前误触。
2. 到公共铺装区域后每 8–12 秒记录一次设备显示的纬度、经度和精度，共 8 次。
3. 记录首次触发耗时、是否连续两次合格采样后触发、旁白在锁屏/切后台时是否继续。
4. 播放完成后打开 App，确认音频控制、完整文字稿和照片任务仍在；照片上传完成后再前往下一站。
5. 沿计划方向离开 120 米，确认没有重复触发；重新进入 App，确认已收集状态没有丢失。
6. 若点位临时封闭、靠近车道、潮线或拥挤出口，不进入危险区域；记录建议替代点，任务可延期。

样本格式：`时间｜纬度｜经度｜精度(m)｜前台/后台｜是否触发｜备注`
