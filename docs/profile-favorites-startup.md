# 个人收藏与启动体验修复

个人主页直接提供「我的收藏」，进入独立 `/favorites` 页面，包含地点和见闻。移除原收藏摘要及「打开完整书架」入口。进入收藏使用 push，返回使用 pop：收藏 → 个人主页 → 原来的发现／见闻／随行栏目；保留原栏目状态。无历史栈时依次回退到个人主页和主页面。

收藏接口的名称实际位于 `target.label`，旧客户端只读顶层 `label`，因此误显示「内容暂不可用」。现在正确解析嵌套字段，兼容旧顶层字段；列表区分载入中、载入失败与已下架，保留取消收藏与撤销。

启动的粗圆圈来自 AuthGate 校验登录，细圆圈来自 DiscoveryPage 读取首页。之前要串行等待登录、城市、景点、故事。现在公开首页数据与登录恢复并行请求；取得城市后，景点与故事也并行请求。登录校验期间显示原品牌标识，首页未完成时显示纸色占位布局，不再连续显示两个整页转圈。私有页面仍需登录校验，不绕过鉴权，也不宣称首次网络请求已消失。定位流程与已加载首页布局不变。

验证：Flutter 全量 310 项测试通过；随后收藏状态提示及撤销完善后，相关 36 项测试通过。覆盖三个主栏目往返（包括系统返回）、真实 API 收藏名称结构、登录等待期间公开请求已开始、城市内容并行请求，以及 390 像素截图。静态检查通过。截图：`mobile/test/goldens/profile-favorites-entry.png`、`mobile/test/goldens/discovery-startup-placeholder.png`。

版本 `0.9.1+32`。Android arm64 release 编译验证通过；验证包使用占位 API 地址，不作为可用安装包交付。正式安装包仍需确认当前动态 API 配置及生产日志凭证。

本次只有客户端变更，无数据库迁移，无后端／CMS 部署命令。需更新客户端才会生效。
