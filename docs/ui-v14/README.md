# 发现、见闻与随行：实现核对

本次按确认的多图设计实现，保留发现首页原始大图素材来源、390×370 整体画布、334×244 照片区域及裁切和翻页动画。首页标题不再跳转，收藏心形仍位于标题右侧；左上角原图标仍通往原个人档案。

见闻增加城市搜索与分页、类型、距离范围和排序，选择后立即请求对应结果。服务端按完整数据集筛选，分页游标绑定筛选条件、位置和账号。未取得位置时展示“距离未知”，距离筛选不会使用模拟坐标。帖子类型保留既有 ID：viewpoint / on_site / experience，显示为拍照机位 / 日常记录 / 经验分享。

发布按钮置于右上角，移除到访日期。照片支持一次多选、最多九张、首图选择、前后移动和删除；草稿与提交保持照片顺序和类型。列表支持单图、双图及三格拼图；详情支持缩略图、左右切换、滑动和大图缩放。

随行中心可直接开启；开启后中心只展示原有距离，右下角“停止随行”独立结束。保留定位权限处理、播放控制、路线选择和行走设置。收藏分为地点与见闻，补齐路线收藏 API 与见闻收藏分页、取消和撤销。

## 验证与上线要求

测试覆盖多图选中与浏览、草稿顺序和类型、返回时保留草稿、即时筛选、旧分页请求不能污染新结果、收藏与取消、随行中心不停止、重复开启防护及原有路线交接。后端测试覆盖距离/类型筛选与游标、九张照片上限和顺序、收藏归属、路线收藏幂等性。

验证结果：Flutter 完整回归 281 项通过；后端完整回归 117 项通过；Flutter 静态分析与改动 Python 文件的 Ruff 检查通过。

这次仅提交代码，没有部署线上服务。新客户端的筛选、坐标和九图发布需要同步更新后端。默认 `COMMUNITY_MAX_MEDIA` 已改为 9（包括 Docker Compose）；总请求默认上限为 96 MiB，单图仍限制为 10 MiB。若部署环境覆盖这些配置或设置反向代理上传上限，需要保持一致。无需数据库迁移。
