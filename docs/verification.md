发布前仍需在 Android/iOS 真机按两个测试账号执行以下人工矩阵，并记录屏幕录像或截图：

1. 账号 A 开始景点 A，播放中返回首页；确认只有可拖动旋转圆球而非横向迷你播放条，暂停时静止，点击回到同一进度。
2. 在播放中与暂停状态分别从景点 A 切到景点 B；确认 A 立即停止、没有重叠音频，圆球封面与点击目标都更新为 B。
3. 进入已完成足迹，逐个点击绿色节点回听；确认锁定节点不可点，回听完成不会移动服务器行走游标或重新锁线索。
4. 在拍照节点选择“稍后再拍”、取消系统相机、离线上传后点击“下一条线索（测试）”；确认音频停止并进入下一节点，恢复网络后照片可重试。
5. 分别从当前旅程与足迹打开本机/服务端照片，验证缩放、关闭、过期占位、拍摄时间与怀旧画框；删除照片后确认 collected count 与重构保持不变。
6. 切换到账号 B，确认看不到 A 的足迹、照片、设置和圆球位置；再退出登录，确认音频与定位停止。切回 A 后，服务端足迹仍在且已完成线索保持解锁。

本变更不会自动执行生产数据库迁移、内容重新发布、服务器部署或商店发布；这些操作须由运营人员按部署与内容清单另行执行。
