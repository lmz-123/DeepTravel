# 旅行准备界面与已确认设计稿对照

版本：0.9.4+35。参考稿：`travel-shared-guides.html`（游玩准备、见闻攻略、我的准备、写攻略四个页面）。本次只更改 Flutter 客户端，无 API、数据库或 CMS 部署。

## 对照结果

| 页面 | 修正内容 |
| --- | --- |
| 游玩准备 | 去掉多余封面图、重复标题和纵向官方信息列表；恢复标题后直接展示票券、两列信息入口、首篇攻略与简洁后续条目、底部我的准备和随行入口。全部 CMS 信息仍可在开放与交通/须知面板访问。 |
| 我的准备 | 左上角标题恢复为我的准备；日期与星期并列；清单放在票券下方；完成数量置于清单标题右侧；每篇攻略来源置于对应条目前；恢复行内添加、票据/须知双入口、页底游玩准备/随行。票据列表进入面板查看，出游管理点击右上方的我的出游。 |
| 见闻攻略 | 恢复作者、标题、发布时间、位置、正文的顺序；准备清单为绿色顶线纸片，含条目数量和细分隔线；导入动作置于页尾。点击评论标题或任意评论可打开评论/回复面板。保留照片、评论回复、收藏功能。 |
| 写攻略 | 去掉编号分类栏和居中重复标题；保留紧凑类型切换；标题、正文、地点直接衔接清单；清单采用单行数字和减号；右上角手绘发布动作保留转圈/防重复提交。页底可保存草稿、展开照片编辑、查看地点。 |

尺寸以设计稿为依据：顶部 66 px；纸张两侧 23 px（320 宽为 19 px）；纸色 `#f5f0e7`；清单纸色 `#eeebdf`；动作色 `#bc4432`；细线 `#d7d2c5`。沿用项目的 Noto Serif SC/Noto Sans SC 字体及原有随行按钮。

首次导入留在原页面，显示成功反馈与查看入口；重复导入不增加条目。准备清单支持直接勾选和行内补充；长按自己补充的条目可以删除。作者来源按原帖分组，查看原文及返回会保留当前准备页。

实际内容会影响高度：无配置价格时不写入示例票价，距离未知时不伪造公里数，攻略分类采用后续确认的“攻略”；照片、草稿和评论编辑保留实际交互入口。源码不包含设计稿的景点/日期/票价常量。
