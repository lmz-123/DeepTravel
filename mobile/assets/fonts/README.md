# Editorial fonts

Bundled from the official google/fonts repository on 2026-09-28 under SIL OFL 1.1.

- Noto Serif SC: Chinese editorial headings, complete character coverage.
- Noto Sans SC: Chinese body fallback.
- Inter: Latin body text.
- Gelasio: open Georgia-compatible numerals; registered as `Georgia` to match the design tokens. No proprietary Georgia font is redistributed.

Variable font weights are used natively. Font files are intentionally bundled rather than fetched at runtime. Each family retains its OFL license, also exposed through Flutter's LicenseRegistry.
