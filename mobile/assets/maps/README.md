# Shenzhen city atlas geometry

Source: https://geo.datav.aliyun.com/areas_v3/bound/440300_full.json

Copied unchanged from the approved city-map prototype on 2026-10-09. The app projects these district polygons locally with Mercator projection; it does not request online tiles or device location. Geometry is a browsing reference, not turn-by-turn navigation. Place coordinates come independently from the published application catalog. Keep the DataV attribution visible in the atlas.
