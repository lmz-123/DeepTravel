## Why

见地已经具备已发布路线、碎片故事、完整故事收听和单路线内容包导入，但首页仍只有单一故事入口，旅行前页面缺少可复用的知识预览、收藏和出发提示，后台也不能在一次可预览操作中导入多个城市的完整内容。需求二需要把现有故事正文作为唯一内容来源，安全地分发到首页、旅行前、现场、足迹和回顾，而不是再造一套会漂移的故事数据。

## What Changes

- 将已审核的碎片故事或完整故事登记为可复用的城市故事目录项；短版预览和现场完整版分别引用现有 canonical fragment/story arc 及其已审核音轨，不复制文本或音频。
- 首页增加后台驱动的“今天听一段城市故事”“3 分钟了解一个街角”“一座城市的一件小事”“你路过但没注意的细节”和“今天适合去哪儿”五类模块，并按当前城市读取已发布内容，不增加偏好问卷或客户端内容枚举。
- 为故事目录补充城市、街区、主题、相关点位、相关故事、内容类型、现实观察细节、可选现场提示、来源/事实状态、审核状态和多渠道投放信息；故事关系与漫游顺序仅作建议，3–8 分钟作为编辑警告而非发布硬门槛。
- 扩展旅行前路线页，使用户在未到现场时可听读主题故事、查看主题/时间/距离/故事方向、同行标签、后台安全/休息/无障碍/天气适应提示，并主动准备音频和文字；不呈现答题或考试。
- 增加账号级城市、景点和主题收藏，收藏只表达用户主动保存，不参与需求一的定位排序或推荐算法。
- 增加一个多城市 JSON 包的校验与 dry-run 预览契约：稳定 ID/包版本识别新增、更新、未变和冲突记录，字段级报错，事务性导入草稿，并复用同一内容模型与发布生命周期。
- JSON 中的媒体部分使用现有媒体描述符、对象引用与校验和，不嵌入二进制文件；缺失媒体在预览/校验阶段明确阻止发布。
- 当前城市没有模块内容时，首页提供后台推荐的其他城市内容和现有切城入口，不显示空白区域。

### Non-goals

- 不建立第二份故事正文、第二套手动编辑模型或绕过审核的“直接发布”导入通道。
- 不实现偏好问卷、个性化推荐算法、实时天气服务、社交收藏榜或基于收藏的定位排序。
- 不改变需求一的景点距离排序，不把路线或故事方向设为强制游览顺序。
- 不在 JSON 中内嵌图片/音频二进制，不自动下载任意远程 URL，也不自动发布生产内容。
- 不删除现有 legacy stop、managed fragment、story arc、home story publication 或单路线内容包兼容入口。

### MVP validation goals

- 当前城市有已发布目录内容时，五类首页模块只展示后台配置且渠道允许的故事；无内容时明确推荐其他城市或允许切城。
- 同一故事在首页、旅行前、现场和旅行后保持同一 canonical 身份与版本谱系，并按渠道使用已配置的短版或完整版；正文更新会使不兼容的旧音频或投放失效而不是静默漂移。
- 用户无需开始旅程即可完成听读、查看路线准备信息、收藏和离线准备，且页面无答题/正确率/强制任务。
- 一个包含多个城市、路线、点位、故事、媒体描述符、标签和投放配置的 JSON 文件可先预览变更，再事务性写入草稿；重复导入同版本不产生重复记录。
- 后台新增城市、目录类型的具体内容或自由标签不要求修改 Flutter 代码。

## Capabilities

### New Capabilities

- `city-story-catalog`: 定义 canonical 故事复用、多渠道投放、首页城市模块、内容类型与事实/审核边界。
- `pretrip-experience`: 定义旅行前听读、路线知识预览、同行标签、出发提示和离线内容准备。
- `traveler-favorites`: 定义账号级城市、景点和主题收藏及隔离/idempotency 行为。
- `multi-city-content-import`: 定义多城市 JSON dry-run、差异预览、幂等事务导入、媒体引用和发布生命周期约束。

### Modified Capabilities

- `experience-client`: 首页增加五类可访问模块、可行动空状态，并保持无偏好问卷和无考试的旅行前体验。
- `route-discovery`: 公共目录增加旅行前故事方向、提示、标签和可复用故事引用，同时保持路线顺序为建议而非强制。

## Impact

- Main API/Alembic：故事目录/投放、故事与城市/街区/主题/点位关系、旅行提示、收藏及导入批次/差异记录；公共首页/旅行前/收藏 API。
- Flutter：城市内容首页模块、通用故事入口、旅行前预览与离线准备、收藏状态和无内容回退；继续复用现有音频所有权与路线详情。
- Independent `Travel-Admin`：配套手动编辑、关系与投放配置、多城市 JSON 上传/校验/预览/导入；只消费主仓库迁移。
- Existing story-listening work：复用已实现的完整故事发布、音轨审核和播放器，不复制 provider、音频或 transcript 工作流。
- 发布与隐私：导入只生成草稿/待审内容；收藏按认证账号隔离；公共 API 只返回正式发布内容。
