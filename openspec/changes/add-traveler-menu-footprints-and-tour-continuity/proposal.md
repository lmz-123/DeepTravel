## Why

见地目前把一次路线体验当成临时页面状态：完成后的路线没有用户可见记录，离开旅程页后也没有正在播放的入口，已走过节点不能主动重听，照片任务还会阻断测试推进。随着真实账号、服务端进度、后台音频和私有照片能力已经就位，需要把这些能力收拢成可恢复、可回顾、可持续播放的完整旅行档案体验。

## What Changes

- 将首页左上角“见地”品牌标识改为可访问的菜单入口，从左侧打开账号抽屉；抽屉展示默认头像、当前用户名，并提供“足迹”“设置”“退出登录”，移除城市选择旁的独立账号头像。
- 新增按当前账号隔离的旅程资料库 API 与足迹页面，展示进行中及已完成路线、完成时间、路线封面、线索进度和私有照片；已完成路线再次进入时复用原完成记录，全部已收集线索保持解锁，不创建新的锁定旅程。
- 在首页加入默认位于右侧、可在安全区域自由拖动并按账号记忆位置的旋转唱片圆球：使用服务端路线封面作唱片中心，外圈显示播放进度；播放时旋转、暂停时静止，点击直接回到对应旅程和当前线索。圆球不承载标题或播放按钮，减少动态效果时改用静态状态；首页再次点击同一进行中景点也直接恢复旅程，不再经过“戴上耳机，开始行走”。任何页面开始播放另一个景点的音频时，先停止旧音频及旧景点监听，再由同一个全局播放器接管新景点，同时保留旧旅程的服务端进度。
- 允许点击已收集的绿色节点切换并重听历史音频；切换会先停止当前音频，但不会回退服务器进度、改变依赖关系或误报新的完成事件。
- 将照片从节点完成条件中解除：听完音频即可收集线索并触发后续节点，模拟定位下点击“下一条线索”会停止当前音频并进入下一节点流程；照片仍可在当前旅程或足迹中稍后补拍、查看和删除。
- 扩展后台内容模型与编辑器，为照片任务配置经典机位、朝向/构图提示等拍摄指导；客户端在拍照前展示安全、站位与构图引导。
- 新增鉴权照片查看链路与怀旧纸质画框组件：拍摄后点击缩略图可查看大图，足迹中也能按节点查看；照片继续保持私有、去 EXIF、按保留期清理。
- 新增实用设置：默认播放速度、真实/模拟定位模式、离线音频下载策略与缓存清理、照片隐私/保留期说明、版本信息。设置按账号在本机隔离；不把内容、路线或音色 ID 硬编码到 Flutter。

### Non-goals

- 不在本次变更中实现社交分享、公开照片墙、点赞、评论、徽章排行或跨用户足迹。
- 不实现头像上传、昵称编辑、找回密码、账号注销或云同步所有客户端偏好；昵称沿用当前账号用户名，头像使用现有默认样式。
- 不新增连续位置轨迹、地图足迹热力图、照片视觉正确性识别或强制拍照证明。
- 不重做路线内容、音频生成流程或历史重构玩法，也不改变未完成路线归档后仍可继续的兼容规则。

### MVP validation goals

- 同一账号完成路线、重启并重新登录后，仍能在足迹中看到完成记录、已解锁线索和未过期私有照片。
- 音频播放时从旅程页回到首页，播放不中断且首页圆球可自由拖动、一键返回；再次点同一路线不会出现首次开始页，改播其他景点时旧音频会先停止且不会再触发旧回调。
- 进行中可点击任一已收集绿色节点重听，再回到当前节点继续；重听不改变服务端收集数。
- 不拍照也能完成节点并在模拟定位下进入下一条；拍照后可立即及从足迹中查看大图，其他账号无法读取。
- 抽屉、首页旋转播放圆球、节点和照片查看具备语义标签、最小触控尺寸、加载/过期/离线错误状态，并通过 Flutter 与后端自动化测试。

## Capabilities

### New Capabilities

- `traveler-library`: 账号抽屉、服务端旅程资料库、足迹列表/详情、已完成路线重访和账号隔离设置入口。
- `continuous-tour-playback`: 首页可拖动旋转播放圆球、跨景点单播放器自动交接、同路线直接恢复、已收集节点切换重听以及模拟推进时的音频交接。
- `photo-keepsakes`: 可选照片留念、内容驱动的经典机位指导、鉴权查看与足迹画框展示。

### Modified Capabilities

- `guided-journey`: 路线启动语义扩展为优先恢复进行中记录，并在已有完成记录时进入只读重访而不是重置为新旅程。
- `experience-client`: 客户端加入全局账号/播放外壳、直接恢复入口和可操作的已完成节点，同时保持可访问性与恢复状态。

## Impact

- `backend/`: 扩展旅程仓储查询与序列化，新增当前用户旅程资料库/足迹读取契约，调整碎片完成与证据删除规则，并扩展照片任务拍摄指导字段、迁移和测试。
- `mobile/`: 扩展领域模型与 repository，新增应用外壳、抽屉、足迹、设置、可拖动播放圆球、鉴权照片查看和怀旧画框；重构活动音频控制器以支持跨页面状态、单一景点音频所有者、直接恢复、历史节点选择及下一节点音频交接。
- `/Users/li/Downloads/Project/Travel-Admin`: 独立仓库同步照片任务字段、内容校验、导入导出和编辑器；需单独验证和提交。
- 内容包：现有路线照片任务补充机位/构图文案并声明为非阻塞留念；保持路线和媒体服务端驱动。
- API：保留现有 `POST /journeys` 与 `/journeys/active` 兼容行为，同时增加账号旅程集合读取及足迹所需的路线/证据元数据；所有私有资源继续要求 Bearer 用户令牌。
- 依赖：优先复用 Riverpod、go_router、Dio、shared_preferences、sqflite、just_audio/audio_service 和现有私有证据存储；仅在实现系统设置跳转或联网策略确有必要时增加最小 Flutter 依赖。
